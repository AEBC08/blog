## 这个站点

Mifumi 是一个静态博客，使用 Nuxt 4 与 Nuxt Content v3 构建，界面组件来自 miuix-vue，样式使用 Tailwind CSS。

- 文章以 Markdown 编写，支持 MDC 组件、KaTeX 与 Mermaid
- 支持浅色、深色与跟随系统三种主题
- 通过 GitHub Actions 部署到 GitHub Pages
