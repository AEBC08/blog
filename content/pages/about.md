## 这个站点

这个博客使用的框架叫 **Mifumi**：一个基于 Nuxt 4、Nuxt Content v3、miuix-vue 与 Tailwind CSS 的静态博客框架。

- 文章以 Markdown 编写，支持 MDC 组件、KaTeX 与 Mermaid
- 支持浅色、深色与跟随系统三种主题
- 通过 GitHub Actions 部署到 GitHub Pages

::
